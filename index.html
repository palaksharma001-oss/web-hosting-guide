Introduction

This website is created as a college project to understand the concept of web hosting. It explains how a website is made available to people through the internet.

What is Web Hosting?

Web hosting is a service that stores website files on a server. It allows people to open a website using an internet browser.

For example, when we open a website, our browser gets the required files from a server and displays the webpage.

Types of Web Hosting

1. Shared Hosting

Many websites use the resources of one server.

2. VPS Hosting

A server is divided into separate virtual servers.

3. Dedicated Hosting

One customer uses an entire physical server.

4. Cloud Hosting

Website resources are provided by multiple servers.

Steps to Host a Website

  1. Create a website using HTML and CSS.
  2. Save the website files.
  3. Choose an online hosting platform.
  4. Upload the files to the platform.
  5. Publish and test the website.
